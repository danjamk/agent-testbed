# Glossary

Terms used in the [README](../README.md).

- **Testbed**: A disposable repository used to try out and exercise a workflow without risk to real projects.
- **secure-agent-workflow**: The workflow, in a separate repository, that runs agents on issues and merges their pull requests through checks.
- **Red-team run**: An agent run that deliberately probes the workflow's limits to find gaps in its security controls.
